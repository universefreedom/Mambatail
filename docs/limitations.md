# Limitations

- Search scores are uncalibrated CLIP cosine similarity, not expert probabilities.
- Reference labels are development-only and source-confounded.
- Query behavior is `UNKNOWN`.
- The public demo uses an existing gallery vector; it is not fresh image inference.
- Continuous-video PTS and dog identity binding are not verified.
- Detector false positives and pose mapping uncertainty remain.
- No clinical, emotion, welfare, or adoption claim is supported.
- Project licensing remains undecided; third-party assets are not redistributed.
